## Platform

## Stack

Static HTML/CSS/JS generated by `tools/site/build_site.py` from `site/template.html` and

## Users

Primary: ISEF judges and fair visitors who scan the QR code at the stand, on a phone or laptop, with a
minute or two to understand the project. Secondary: developers and users who install Nitaq and connect it
to their own AI agent.

## Product Purpose

Nitaq (نِطاق, "scope") is an ISEF research project and open-source tool that stops AI agents from acting
on instructions injected into what they read (e-mails, web pages, skill files, tool descriptions). It
judges every tool call against the task's scope (where it goes, what it reads or carries), not the language
of the text, so Egyptian Arabic, Arabizi (Franco) and Base64 attacks are handled the same way.
Success on the site: a visitor tries Nitaq themselves or watches the demo video, and leaves understanding
"the agent can be fooled; the scope cannot".

## Positioning

Content filters depend on language; Nitaq's action guard does not. It is one product with several faces
(web app, desktop app, CLI, terminal agent on Gemini, MCP gateway for cloud agents) and a research
benchmark behind it, built and tested on Arabic and Arabizi attacks.

## Operating Context

- Shown live at an ISEF stand: terminal agent (`nitaq agent`) with two booby-trapped skills, the MCP
  gateway with a local approvals dashboard, a cloud AI (claude.ai custom connector) through a tunnel.
- The site is reached from a QR code; the demo video is `demo/Nitaq_Full_Demo.mp4` (about 12 MB).

## Capabilities and Constraints

- Everything runs locally; the web app checks files on the device. The gateway guards only the tools
  connected through it. Supported agents for protection: Claude Code and Gemini CLI only.
- All attack examples are synthetic: attacker addresses end in `.test` / `test.local`, data is fake.
- Results shown anywhere must be the program's real output; numbers must not be changed or invented.
