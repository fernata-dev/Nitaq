# Surface brief: Nitaq site (site/template.html, ar + en)

Mode: Persuade. Audience: ISEF judges and fair visitors arriving from the stand's QR code, phone first;
developers second. Job: understand "the agent can be fooled; the scope can't" in one viewport, then try
Nitaq (scan a skill/e-mail in the browser, or connect their own gateway over MCP) or watch the demo video.
Proof on hand: real transcripts (docs/media/agent-*.txt), the policy-computed demo data, the demo video,
gateway dashboard capture. Constraints: static, strict CSP, self-hosted fonts, honest limits kept.

## Direction contract

THESIS: Every attack is a case file. Nitaq is the bureau that sweeps each source, types out the hidden
order it found, and stamps the risky action «مرفوض — خارج النطاق». Refuses the security-SaaS default
(dark navy, neon, shield icons, feature-card grid).

OWN-WORLD: manila and file-tan paper ground, ink-black rules and frames, case-gray halftone, alarm red only
for the refusal stamp and refused rows. Heavy Kufi display caps like stencilled file labels, typed Naskh
and mono record lines, ruled index tabs, frame grids with coarse halftone, angled rubber stamps.

STORY: the visitor watches one case play (source, sweep, typed injection, stamp), believes language
doesn't matter because the stamp lands on the action, then opens a case themselves (skill/e-mail check,
MCP connect) or plays the film.

FIRST VIEWPORT: file-tab index rail on the inline-start edge; case title + one-line verdict + two actions
(try a case, play the film) in the left two-fifths; on the right a 3x2 surveillance grid of the four
sources with a reticle sweeping, the injected line typing in, and the red stamp landing last. Below, a
ruled decision log strip.
