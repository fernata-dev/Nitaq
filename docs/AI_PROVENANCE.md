## What the AI did NOT produce and the student must

1. **The attack texts that count.** Egyptian Arabic, Arabizi and MSA injections written by the
   student in `data/attacks/student_written/` (see the README there). The AI drafts must be
   replaced, or excluded with `--authors student`, before any conclusion.
2. **Benign everyday texts** in the same varieties (`data/benign/student_written/`).
3. **The real-model pilot run** on the student's machine, with the date and model recorded.
4. **All interpretation**: abstract, poster, conclusions, discussion. The AI was instructed not to
   write them and did not. The generated `CLAIMS_ALLOWED.md` lists only what numbers support.
5. **Understanding the code well enough to explain every design choice to a judge.** Use
   `docs/DESIGN.md` and the tests as a guide.
